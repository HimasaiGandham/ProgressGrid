**PROJECT INTRODUCTION**
  Progress Grid is a web-based task management system designed to help teams track and manage project progress in a simple and visual way.
  The system provides a centralized grid where team members can view assigned tasks, update their task status, and monitor overall project progress. 
  It improves visibility, accountability, and team coordination by keeping project information organized in one place.
  
**Key Features**

  Visual progress tracking
  Task status management
  Team member and task assignment
  Real-time progress updates
  Simple and user-friendly interface
  Centralized project data management
  
**Technology Stack**

**Frontend**: HTML, CSS, JavaScript
**Backend**: Java, Spring Boot
**Database**: MySQL

**Project Goal:**
  To provide a simple and effective platform that makes it easier for teams to understand what needs to be done,
  who is responsible, and how much of the project is completed.
